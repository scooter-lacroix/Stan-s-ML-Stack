## RESEARCH VERDICT (ground truth the reviewer should confirm the code reflects)

Exhaustive primary-source research (official **ROCm/flash-attention** README,
`ROCm/composable_kernel#1434`, migrated to `ROCm/rocm-libraries#4224`)
established:

- Both Flash Attention backends ship from the **same** `ROCm/flash-attention`
  repo. **CK is the default backend**; Triton is enabled via
  `FLASH_ATTENTION_TRITON_AMD_ENABLE=TRUE`.
- **CK backend** supports MI200/250/300/355 + RDNA3/4, fp16/bf16, head dim ≤256.
  **RDNA3 has NO backward pass** (open feature). **RDNA4 gains backward only with
  `deterministic=False`.**
- **Triton backend** supports CDNA + RDNA, fp16/bf16/fp32, **forward AND
  backward**, causal, MQA/GQA, rotary, ALiBi, paged, FP8.
- Real-world cost (issue #1434): LoRA training that fits in 16 GB on NVIDIA OOMs
  on 20 GB AMD without the fused backward. So on RDNA3, FA-CK = inference/forward
  acceleration only; training backprops fall back to unfused PyTorch SDPA.

The reviewer should confirm the code's experimental labeling + capabilities
text is consistent with this ground truth.
